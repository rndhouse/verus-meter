# 07.5. Sections, checkpoints and diagnostics

Dependencies: 07.1–07.4.

## Work

- [ ] Apply the global proof to a section and its covered descendants. Compose its
  allowance with live parent storage. Require its descendants to join before section exit.
  Preserve the fixed-bound restrictions on sections and checkpoints.
- [ ] At a current-storage checkpoint, bound every permitted state there. At a peak
  checkpoint, include every earlier covered state. Respect the nearest budgeted scope and
  the caller-frame convention. Reject cross-thread references to an ancestor's checkpoint
  history. Keep proof metadata erased. Runtime peak queries evaluate declared formulas
  under their existing preconditions. Check static/runtime agreement for any newly
  admitted size query.
- [ ] Give a source diagnostic that distinguishes insufficient bytes, missing
  synchronization or lifetime evidence, and unsupported operations. Identify the
  contributing allocation, instance, result or release where available. Keep solver
  failure or timeout as an unproved obligation.

## Completion and validation

Exercise a joined child within a section, an outstanding descendant at section exit and a
prohibited ancestor checkpoint reference. In a program where a child may still own a
buffer, reject a checkpoint that ignores the child. After its verified release and join, a
smaller current bound can pass while the earlier peak still matters. Exercise runtime
queries and check diagnostics on representative failures from 07.1–07.4. Close the parent
after reconciling every original criterion with source tests and running the applicable
integrated checks in the concurrent TODO index. TODO 08 remains the separate core-wide
audit.
