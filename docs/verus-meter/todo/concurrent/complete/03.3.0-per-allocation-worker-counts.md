# 03.3.0. Count references per allocation

**Completed in implementation commit `13c440bce`.** Given a vector of outstanding worker handles, prove how many strong references its workers hold to each allocation. A vector length suffices for uniform captures. When some workers capture buffer A and others capture B, popping a handle moves one worker out of the vector. Its references remain accounted for through the handle until the join reconciles that worker's captures and result.

## Work

- [x] Derive counts from executable construction, publication, container operations and joins. Prove initialization, transitions and loop back edges for zero, one and many iterations. Each handle selects one outstanding occurrence, even when the same spawn site runs repeatedly.
- [x] Use each occurrence's actual capture multiplicities and checked result. Preserve the existing join mapping from worker family to returned allocation. A join can move a reference into the result while releasing the worker's other claims.
- [x] Preserve exact membership through full drains, partial drains and branches on the changing collection length. Keep these proofs compositional using the existing construction and collection laws.
