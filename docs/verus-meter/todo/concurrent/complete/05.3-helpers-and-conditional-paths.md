# 05.3. Helpers and conditional paths

Use the transitions from 05.1 and the escaped ownership from 05.2 in ordinary
function summaries. A worker that conditionally pushes a box and unlocks inside
a helper should expose the same possible payloads as the direct implementation.
A release-only helper already works at `b8e289e04`.

Start with `source/vir/src/resource/memory/synchronization/helpers.rs`,
`source/vir/src/resource/memory/calls.rs` and the shared payload regressions.
Use the same checked summary interface for calls in workers and in ordinary functions.

## Verified behavior

Implementation `dffa1e821` binds a moved guard to its mutex's protected storage
before the call. Nested helpers update the same storage. A returned
`Some(guard)` carries that acquisition into the caller. On the released path the
caller can lock the same mutex again. Trying to acquire it through an alias
while the returned guard is held fails, as does unwrapping the result without
establishing that it is `Some`.

The direct conditional push, an early return that skips the push, and the
nested helper produce the same local bounds at join. After the last mutex
owner is dropped, 42 bytes cover the returned option, its possible 32-byte box
and the caller's live flag. The path that skips the push proves 10 bytes. A
41-byte claim for the path that can return the box fails. A consuming helper
can also return early with `None`, return a popped box, or return a fresh box.
The result and the remaining mutex contents follow the same source condition.
A helper with extra scratch proves 81 bytes at its checkpoint and rejects 80.

The regressions are in
`source/rust_verify_test/tests/resource/memory/synchronization/helpers.rs` and
`source/rust_verify_test/tests/resource/memory/synchronization/shared_payloads/joined.rs`.
Precision here covers representable fixed-worker histories, immutable scalar
conditions, and plain owned results on source exits. General owning expressions
retain the existing branch-merge restrictions. 05.4 covers repeated acquisitions
and loop-selected mutexes. 07 owns the total concurrent peak.
