Dependencies: 06, 07.2.

## Work

  each intact witness to its actual instance, acquisition and covered bytes. Preserve that
  identity through a checked helper or worker handoff.
- [x] Derive `min(n, k) * b` for homogeneous scratch with at most `n` workers, immutable
  capacity `k` and a proved aggregate of at most `b` bytes per holder. Express the minimum
  with supported budget syntax. Include waiting and failed attempts in the total. Respect
  explicit permit release and the occupied capacity of discarded permits.
- [x] Use the same composition for a custom Verus-verified exclusive protocol and for
  verified RwLock roles. Allow readers to overlap. Apply writer/reader and writer/writer

## Completion and validation

Verify whole-operation bounds for the semaphore, a custom exclusive protocol and the
supported RwLock roles. Exercise `k < n`, `k >= n`, and zero capacity using a nonblocking
attempt. Release a permit before dropping its buffer, substitute a different semaphore of
the same capacity, and put two buffers under one permit. Each mutation must lose any tight
bound it invalidates. Reject an unjustified holder bound. A one-buffer allowance must fail
when two readers can each hold a buffer. Choose sizes that make each overlap observable
after accounting for the other live storage.

## Implementation and validation

Feature commit `0e46c2d42` proves the total for a counted family using
`512 + 192 * n + (if n <= k { n } else { k }) * b` in the executable
regression now published at `examples/resource/memory/concurrent/semaphore.rs`. The last term covers scratch.
The other terms cover the caller, handles, workers and synchronization calls.
The example checks zero permits, fewer permits than workers, and spare permits.

A verified constructor identifies the actual argument for the instance’s
holder limit. The acquisition must relate the intact permit to that limit.
An object that identifies a real semaphore but reports its own limit of zero
still incurs the real buffer charge. Releasing early, switching to another
semaphore of equal capacity, allocating on failure, and keeping two buffers
under one permit each invalidate the tested smaller allowance.

A custom exclusive guard can move into a worker and through a checked helper.
The 2,400-byte allowance verifies for the same lock and fails when another
worker can acquire a different lock. Two RwLock readers can overlap. A writer
excludes both another writer and a reader on the same lock. The counted analysis
can conservatively group a phase with several intact witnesses under one of them.

All 1,254 memory integration tests, 65 atomic-library tests and 47 resource
examples passed. The rebuilt standard library verified 2,438 checks with zero
errors. The VIR unit tests, upstream regressions, formatting, Clippy and strict
VIR rustdoc also passed. [07.4](07.4-helpers-and-retained-storage.md) extends these checks through helper calls, retained results and nested workers.
