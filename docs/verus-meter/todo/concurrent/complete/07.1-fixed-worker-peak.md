# 07.1. Fixed workers and mutual exclusion

Dependencies: 01–06.

## Work

- [x] Use the verified phases and allocation identities from 03–06 to generate a bound on
  all bytes live at the same time. Start with two fixed workers and a symbolic scratch
  size. Use the ordinary function contract on a closed operation with both workers joined.
- [x] Prove initialization and preservation as either worker steps. Include spawn, blocked
  acquisition, lock and unlock, drop, completion and join, and the temporary storage
  needed for each step. Charge the caller, captures, handles and shared backing according
  to the source model. Count each backing once across its aliases.
- [x] Bound the total scratch held under one acquisition, including multiple buffers.
  Apply exclusion only to acquisitions of the same mutex. Generate and check the proof
  before accepting a concurrent contract. Keep the existing rejection for any path whose
  total still lacks a proof.

## Completion and validation

Two actual workers each allocate and free a buffer of size `b` under one mutex. The
ordinary verifier accepts a **total** allowance that includes one such buffer and all
other live storage. With distinct locks or no exclusion, demonstrate a reachable overlap
of two buffers and verify a sufficient total. Moving allocation before locking or drop
after unlocking must break the one-buffer claim for inputs where the difference exceeds
any slack. Also check two simultaneously live buffers under one guard. Establish failure
at the claimed byte bound.

## Implementation and validation

Feature commit `5e4c51be4` covers fixed, directly joined workers returning unit.
At each caller observation, the proof uses completion tags to identify outstanding
workers. It combines their checked byte costs across the mutex states that can
coexist. A vector's symbolic reservation must cover its current charge at each
worker observation that uses it. Export waits for the byte proof and Rust checks.

In `source/rust_verify_test/tests/resource/memory/fixed_workers.rs`, two workers
that reserve and drop `b` bytes under one mutex verify a total of `b + 108`.
One byte less fails. Distinct mutexes verify `2 * b + 158`. Allocating before
locking or unlocking before drop defeats the one-buffer bound. The tests also
cover two live buffers under one guard, failed acquisition, caller storage across
join, and export. All 1,246 memory integration tests and 47 resource examples passed.
