# 03.3. Symbolic populations and shared ownership

**Next: 03.3.0.** Prove which shared allocations remain live when workers in one vector hold different buffers. TODOs 01–02 and 03.1–03.2 are complete.

## What works today

The implementation branch tracks individual workers in supported symbolic spawn and join loops, including partial drains, nested workers, and transfers of handle collections. In the publishing thread, an indexed join can identify which captured `Arc` a worker returned. Its identity proof and byte accounting use the same mapping. The existing symbolic drain covers workers that all capture both allocations and each return one. Changing each worker to capture only the allocation it returns exposes the next open proof.

The baseline is implementation commit `61d7cd5f3`, with 1,060 passing memory integration tests. The earlier test cases, limitations and commit-by-commit evidence are preserved in this document at main commit `cbf48b8bd`.
