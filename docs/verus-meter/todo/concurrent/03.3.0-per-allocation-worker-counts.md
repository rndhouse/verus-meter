# 03.3.0. Count references per allocation

**First child of 03.3.** Given a vector of outstanding worker handles, prove how many strong references its workers hold to each allocation. A vector length suffices for uniform captures. When some workers capture buffer A and others capture B, popping a handle moves one worker out of the vector. Its references remain accounted for through the handle until the join reconciles that worker's captures and result.

## Work

- [ ] Derive counts from executable construction, publication, container operations and joins. Prove initialization, transitions and loop back edges for zero, one and many iterations. Each handle selects one outstanding occurrence, even when the same spawn site runs repeatedly.
- [ ] Use each occurrence's actual capture multiplicities and checked result. Preserve the existing join mapping from worker family to returned allocation. A join can move a reference into the result while releasing the worker's other claims.
- [ ] Preserve exact membership through full drains, partial drains and branches on the changing collection length. Keep these proofs compositional using the existing construction and collection laws.

## Done when

Start from `mixed_arc_workers_reconcile_a_symbolic_number_of_results`. It drains `2 * n` workers that capture both buffers. Change each family to capture only the buffer it returns. Prove the selected drops and final byte bound for symbolic `n`. Also prove the variant that captures both, drains to one and joins the last handle outside the loop, and a drain that branches on the remaining length.

Mutate the executable program to keep the larger buffer against the smaller bound. Require a byte-bound failure. Check that an invented count or a second removal of the same occurrence cannot discharge an obligation. Use the actual handles and allocations throughout.

Start in `source/vir/src/resource/memory/loops/populations.rs` and `source/vir/src/resource/memory/workers/shared.rs`. The source regression is in `source/rust_verify_test/tests/resource/memory/worker_populations.rs`.
