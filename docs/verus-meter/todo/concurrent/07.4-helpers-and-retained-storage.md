# 07.4. Helpers, retained storage and nested workers

Dependencies: 07.1–07.3.

## Work

- [ ] Compose checked helper and worker summaries into the global proof. Include live
  caller storage and callee workspace. Preserve the phases in which other workers may run,
  including while a helper blocks. A helper's declared peak alone cannot establish a
  release or a transfer.
- [ ] Follow a buffer through helper returns, conditional release, shared payload
  replacement, worker completion, delayed join and final drop. On each branch, charge it
  continuously to the appropriate owner. Reacquiring a guard starts a new interval. Charge
  retained storage at the same time as later scratch whenever the two can coexist.
- [ ] Compose supported acyclic worker subtrees, including heterogeneous workers or finite
  families using checked sums or a proved bound for the family. Preserve correlations
  needed for sequential reuse. Accept legal escapes when the total covers them. When a
  correlation is unavailable, require a stronger proof or report the unproved bound.

## Completion and validation

Direct and helper-factored versions must verify the same tight total when their modeled
workspaces agree. Include each version's own frame costs when they differ. A worker that
returns an owned buffer must still contribute its bytes after completion while another
worker allocates. Check skipped and repeated acquisitions, a helper with extra workspace,
and a nested worker whose live storage changes the enclosing bound. Pair scratch freed
before unlock with an owning element pushed under the same mutex. For the vector count the
documented slots and retained payloads across pushes, with no private resize surcharge.
Verify sufficient totals and reject bounds that omit reachable live storage.
