# 03.3.1. Preserve ownership across transfers

**Depends on 03.3.0.** When a join handle, worker collection or returned alias moves to a helper or another thread, the receiver must get the exact worker or allocation identity, the references it now owns, and any outstanding join obligation. Existing collection transfers and local moves of returned aliases are the starting point.

## Work

- [ ] Carry the selected worker's checked inputs, possible outcomes and shared references through supported helper calls and worker captures/returns, including native joins and owning results. Preserve the backing of transferred collections and the outstanding members of a partially drained collection.
- [ ] Keep distinct dynamic visits to the same join site distinguishable while earlier results survive. Substitute the actual caller, nested parent and loop occurrence in scalar snapshots, aggregate views and ownership descriptors. Cover repeated publications and captured collections whose construction depends on the enclosing occurrence.
- [ ] Check who may join each worker after transfer in an acyclic worker tree. Preserve descendant obligations across scope exit. Reject detach, lost descendants and self or cyclic waits.

## Done when

Pass a handle from a mixed collection to another worker or helper, join it there and return its selected alias. Keep two results from the same join site alive at once. Prove that each still refers to its own buffer and that a local move or clone preserves its identity. Swapping the selected buffer must break a bound that fits only the smaller one.

For a helper returning a collection drained to `keep <= n`, verify the caller's complete drain. Changing its condition from `rest.len() > 0` to `rest.len() > 1` must report the outstanding handle at cleanup at the default solver limit. Exercise a stale capture substitution, a foreign allocation and a lost or cyclic join as negative cases.

Start in `source/vir/src/resource/memory/workers/populations.rs`, `source/vir/src/resource/memory/workers/results.rs` and `source/vir/src/resource/memory/transfer/calls.rs`. Implementation commits `eddebc1bc` and `a46da749c` cover existing transfers.
