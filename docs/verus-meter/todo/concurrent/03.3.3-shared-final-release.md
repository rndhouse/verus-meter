# 03.3.3. Prove final release

**Depends on 03.3.0–03.3.2.** Prove strong-reference conservation across the covered threads. Today the publishing thread can conservatively keep a shared allocation charged until join. To prove earlier release, identify the executable destructor that removes its last strong reference in each permitted interleaving.

## Work

- [ ] Reconcile references from locals, captures, completed results, fixed fields and supported containers against the same allocation. Strong creation, clone and drop change ownership. Borrows, moves, proof branches and transfers of byte accounting must preserve the number of live strong references.
- [ ] Account for handles, model control storage and the backing allocation separately. Follow the payload's owned storage, including incoming buffers and nested strong or worker handles within the supported acyclic domain. Release each allocation once its own final owner drops. Preserve the protected allocation identity needed by 05.
- [ ] Cover roots created on repeated coordinator visits and publication that leaves no fixed handle with the publisher. Check worker-local destruction against references elsewhere in the domain. Keep the explicit exclusions for weak references, raw ownership, cycles and unmodeled reclamation operations.

## Done when

Use two workers with aliases of one allocation whose payload owns a buffer. Drop the publishing thread's handle, vary which worker drops or returns its alias, and prove that the backing survives the first drop and is released exactly once at the last destructor, including a last drop before join. Cover zero workers, retained results and an owned payload with multiple internal allocations.

Keep one extra executable clone alive and require a premature-release claim to fail. Check a one-byte reduction at a live checkpoint, including the known vector-plus-box payload case (89 bytes versus 88), and reject excluded ownership operations. The symbolic negative case needs a budget diagnostic at the default solver limit. Global conservation here supplies a premise for 07's total-byte proof.

Start in `source/vir/src/resource/memory/shared.rs` and `source/vir/src/resource/memory/workers/shared.rs`. Implementation commits `0cb0da23b` and `0d2e4297e` cover fixed-worker aliases and existing indexed payload accounting.
