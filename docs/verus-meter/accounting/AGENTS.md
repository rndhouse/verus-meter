# Maintaining the accounting guides

- Keep the [README](README.md) to the aim of source accounting and links that help readers find a rule.
- Change a core page only when the answer to its question changes. Revise the existing principle before adding a bullet.
- When a fix brings the verifier into line with a documented rule, record the case in a regression test. Edit the guide only if its description has become inaccurate.
- Keep operation-specific details on focused pages. Add an example when it answers a distinct reader question. Replace an existing example when a clearer one teaches the same rule.
- Give each rule one home and link to it elsewhere. Use short bullets under descriptive headings.
- Track discrepancies in the [accounting audit](../todo/audit-and-correct-source-accounting.md). Keep fix histories, test counts, and solver investigations in Git.
