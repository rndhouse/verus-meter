# Maintaining the accounting design agreement

- Use these files to record agreed decisions about what Verus Meter should prove. If the boundary is unsettled, raise the decision for discussion before recording it as policy.
- Extend the lowest-level page that covers a decision. Adding a supported operation or a distinguishing example is a routine detail-page edit. When adding a page, link it from the nearest index.
- The higher a rule sits, the stronger the reason to change it. Before extending a principles page, identify which general decision has changed and why the existing rule no longer suffices. Prefer revising that rule. Keep the top-level [README](README.md) to the aim and the main topics.
- Give each rule one home and link to it elsewhere. Use short bullets under descriptive headings.
- Keep fix histories, test counts, and solver investigations in Git.
